Инструкция по установке приложений

Поскольку официальный магазин закрыт, файлы формата .appx и .appxbundle устанавливаются на Windows 10 Mobile вручную с помощью режима разработчика.

Шаг 1. Включение режима разработчика на телефоне

  1. Возьмите ваш смартфон и откройте Параметры.
  2. Перейдите в раздел Обновление и безопасность ➡️ Для разработчиков.
  3. Поставьте галочку или переключатель напротив пункта Режим разработчика.
  4. Подтвердите действие во всплывающем окне (нажмите «Да»). Телефон может ненадолго задуматься, загружая необходимые пакеты.

Шаг 2. Простая установка (Прямо с телефона)

Если вы скачали файл приложения напрямую через браузер вашей Lumia:

  1. Откройте стандартное приложение Проводник (Диспетчер файлов).
  2. Найдите скачанный файл формата .appx или .appxbundle (обычно они лежат в папке «Загрузки» / Downloads).
  3. Просто нажмите на файл один раз. На экране появится системный запрос: «Установить приложение?». Нажмите Установить.
  4. Важно: Никаких полосок загрузки не появится. Смартфон будет устанавливать его в фоновом режиме. Подождите 1–2 минуты, и приложение появится в общем списке всех программ на телефоне.
Внимание! Если при нажатии ничего не происходит или выдает ошибку, значит, приложению нужны зависимости (дополнительные файлы), либо файл поврежден. В таком случае установку делают через ПК и функцию Device Portal.
